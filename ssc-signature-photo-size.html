SSC CGL, CHSL and GD Constable: signature size and photo rules

SSC applications no longer take an uploaded photo: the photo is captured live inside the form. You upload only a JPG signature of 10–20 KB, about 6 cm wide and 2 cm high.

Each Make it button opens FileFit with that exact size already filled in. Your file is processed in your browser and never uploaded. FileFit keeps the result inside the limit whether the portal counts 1 KB as 1000 or 1024 bytes.

Good to know

  • The main text of the notices says about 6.0 × 2.0 cm, while the annexure of some notices (CGL, CHSL) says about 4.0 × 2.0 cm. The file size, 10–20 KB, is the same everywhere, so get that right first.
  • The GD Constable notice adds that the signature should be scanned at 300 DPI.
  • Per the notices, applications authenticated with Aadhaar are not rejected on these photo/signature grounds.
  • MTS, JE, CAPF and other SSC exams use the same application module; check your own notice.

Source

SSC notices: Combined Graduate Level Examination 2026, Combined Higher Secondary (10+2) Level Examination 2026 and Constable (GD) Examination 2026, Staff Selection Commission — official website: https://ssc.gov.in/. Always read the latest official notice before you apply; exam bodies change these rules between years.
