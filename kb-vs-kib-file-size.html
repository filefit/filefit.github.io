KB vs KiB: why a file “under 100 KB” can still be rejected

Upload limits are written in kilobytes (KB) or megabytes (MB), but those units mean slightly different numbers in different places. Near the limit, that difference decides whether your file is accepted.

Two meanings of “kilobyte”

  • Decimal: 1 KB = 1000 bytes, 1 MB = 1,000,000 bytes. Used by phone storage, macOS Finder and many websites.
  • Binary: 1 KiB = 1024 bytes, 1 MiB = 1,048,576 bytes. Windows Explorer shows these values but labels them “KB”.

So the same file can be described with two different numbers:

File size in bytesin decimal KB (÷1000)in binary KB (÷1024)
20,00020.019.5
50,50050.549.3
102,000102.099.6
204,800204.8200.0

Why it causes rejections

Suppose a form allows “up to 50 KB” and checks with 1000-byte kilobytes. Your Windows computer says the file is 49.3 KB, but the website sees 50,500 bytes = 50.5 KB and rejects it. The opposite happens with minimums: a file of 20,000 bytes is 20.0 KB to one system and 19.5 KB to another.

The safe rule

  • For a maximum of N KB, keep the file at or below N × 1000 bytes (the smaller number).
  • For a minimum of N KB, keep the file at or above N × 1024 bytes (the larger number).

Example: “20–50 KB” is safe between 20,480 and 50,000 bytes. A file in that window passes whichever way the website counts. FileFit applies this rule automatically for every limit you enter.

How to see the exact byte count

  • Windows: right-click the file → Properties → “Size” shows the exact bytes in brackets.
  • Mac: select the file → File → Get Info → “Size” shows bytes.
  • Android/iPhone: most file manager apps show details including size; for exact bytes use a computer.
